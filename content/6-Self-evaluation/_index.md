During my internship at **AWS Vietnam** under the **First Cloud AI Journey (FCAJ)** program from **June 15, 2026** to **July 31, 2026**, I had the opportunity to learn, practice, and apply the computer science & software engineering knowledge acquired at university to a real-world cloud computing environment.  

I actively participated in designing and building the **Movie Recommendation System on AWS**, a user data-driven movie suggestion platform featuring real-time ML inference on Amazon SageMaker, containerized FastAPI backend, React/Vite frontend, DynamoDB hot storage, and S3 cold storage. Through this project, I significantly improved my technical and professional skills in **AWS cloud architecture, Machine Learning recommendation modeling (Implicit ALS, Content-Based, Hybrid RRF), Python/FastAPI backend engineering, React/TypeScript frontend development, Docker containerization, GitHub Actions CI/CD automation, technical documentation, and cross-team collaboration**.
