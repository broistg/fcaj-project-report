### Mục tiêu Tuần 1 (Proposal Giai đoạn 1 - ML Engineer Focus):

* Khởi động chương trình thực tập FCAJ, tiếp nhận vai trò **Kỹ sư Machine Learning (ML Engineer)** chịu trách nhiệm toàn bộ kiến trúc Machine Learning và Amazon SageMaker pipeline.
* Tìm hiểu tổng quan kiến thức AWS Cloud Fundamentals và các dịch vụ đám mây ML cốt lõi (IAM, S3, DynamoDB, SageMaker, VPC).
* Thiết lập môi trường máy trạm nhà phát triển ML: Cấu hình Python/Jupyter/Conda, AWS CLI v2, IAM ML developer profile tại region `ap-southeast-1` và xác minh kết nối SDK.

### Kết quả đạt được Tuần 1:

* Tiếp nhận chính thức vai trò Kỹ sư Machine Learning (ML Engineer) phụ trách toàn bộ pipeline Machine Learning trên Amazon SageMaker.
* Thiết lập thành công môi trường phát triển ML cục bộ (Python 3.11, Jupyter, Scikit-Learn, Pandas) và cấu hình an toàn AWS CLI v2.
