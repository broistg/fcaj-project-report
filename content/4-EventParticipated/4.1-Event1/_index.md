# Technical Summary Report: FCAJ Technical Meetup #1

### Event Overview

* **Event Name:** FCAJ Technical Meetup #1 – Containerization, Security & GraphRAG
* **Date & Time:** Saturday, June 06, 2026 (09:00 – 12:00)
* **Location:** AWS Vietnam Office / Community Meetup
* **Role:** Attendee

---

### Featured Speakers & Technical Presentations

1. **Bảo Huỳnh – *Docker: A Containerization Technology***
   * Explored container isolation mechanics, image layering, and Dockerfile optimization strategies.
   * Demonstrated local container orchestration with Docker Compose for multi-container microservices environments.

2. **Lê Hoàng Gia Đại – *Combining AWS WAF with Machine Learning for Cyber Attack Detection on AWS***
   * Presented a security architecture combining Amazon CloudWatch, Lambda, and SageMaker ML models to detect anomalous web traffic.
   * Showcased automated updates to AWS WAF IP sets and rule groups to block zero-day application attacks in real-time.

3. **Nguyễn Quốc Bảo – *Multiplayer in the Cloud: Connecting Godot Clients with AWS WebSockets***
   * Introduced real-time cloud gaming architecture utilizing Amazon API Gateway WebSockets and AWS Lambda.
   * Explained state synchronization, low-latency message routing, and serverless backends for indie game developers.

4. **Trương Phước – *Effective Teamwork Strategies in Tech Projects***
   * Shared practical experience on Agile/Scrum team alignment, Git workflow conventions, and asynchronous communication patterns.
   * Highlighted methods to prevent technical debt and foster cross-functional collaboration.

5. **Vinh Trần – *From IT Helpdesk to Senior Sysadmin: Self-learning Journey and Cloud-DevOps Transition***
   * Shared a personal career progression roadmap from IT support to cloud systems administration.
   * Outlined self-study paths for AWS certifications (SAA, DVA, SAP), Linux administration, and Infrastructure as Code (Terraform).

6. **Việt Phát – *AWS Neptune for Building a Graph Knowledge Base for GraphRAG***
   * Deep-dived into Amazon Neptune graph database features for modeling complex enterprise entity relationships.
   * Demonstrated integrating graph knowledge bases with Retrieval-Augmented Generation (GraphRAG) to enhance LLM context accuracy.

---

### Key Takeaways & Work Application

* **Containerization Best Practices:** Applied Docker multi-stage builds and container composition to isolate the FastAPI backend and React frontend services in our Movie Recommendation project.
* **Security & Infrastructure Controls:** Understood the importance of combining automated threat detection (WAF + CloudWatch) with IAM least-privilege policies.
* **Knowledge Graphs in AI:** Gained valuable perspective on hybrid knowledge representation (Vector + Graph databases) for advanced AI inference pipelines.
